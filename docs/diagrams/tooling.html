just-vcf's tooling seat: the instance layer

This page shows what this repository's tooling seat changes over the seats kit's tooling role. The kit's presenter drew it from docs/seats/TOOLING.md and the [seat.tooling] tables in .blueprints.toml at this repository's commit ad48ef7, against the kit at v0.1.115, the tag this clone pins. It lies over two layers from the kit: docs/diagrams/base.html, what every session holds, and docs/diagrams/tooling.html, the kit's own tooling seat. Both are in the pinned kit copy, which the session's $BLUEPRINTS_KIT names.

This page draws the texts alone. The kit's flow analysis has not run yet, so nothing here has been checked against how the seat actually behaves.
